# Actividad de aprendizaje

## Análisis de un problema desde diferentes enfoques de Inteligencia Artificial

## Propósito

Aplicar los conceptos estudiados en el subtema 1.2 mediante el análisis de un mismo problema desde los enfoques simbólico, conexionista y estadístico/probabilístico.

La finalidad es identificar que un problema de Inteligencia Artificial puede abordarse mediante diferentes paradigmas y que la elección del enfoque depende de las características del problema, los datos disponibles y los requerimientos de la solución.

---

## Instrucciones

Selecciona **uno** de los siguientes casos:

### Caso A. Reconocimiento de imágenes

Desarrollar un sistema que determine si una imagen contiene un **perro o un gato**.

### Caso B. Diagnóstico de fallas

Desarrollar un sistema que permita identificar posibles **fallas en una máquina** utilizando información como temperatura, vibración, sonido u otras variables disponibles.

### Caso C. Detección de congestión vehicular

Desarrollar un sistema capaz de determinar si una vía presenta **tráfico normal o congestión vehicular**.

### Caso D. Evaluación de riesgo de impago

Desarrollar un sistema que estime el **riesgo de que una persona incumpla el pago de un crédito** utilizando información disponible sobre la solicitud.

### Caso E. Detección de fraude

Desarrollar un sistema que determine si una **transacción financiera presenta características potencialmente fraudulentas**.

---

## Desarrollo

Analiza el problema seleccionado desde los tres enfoques revisados en el subtema.

### a) Enfoque simbólico

Explica cómo podría resolverse el problema mediante conocimiento explícito y reglas.

Incluye:

a) Información que necesitaría el sistema

b) Ejemplos de conceptos o símbolos utilizados

c) Al menos tres reglas de ejemplo

d) Forma en que el sistema obtendría una conclusión

e) Una ventaja del enfoque

f) Una limitación del enfoque

---

### b) Enfoque conexionista

Explica cómo podría utilizarse una red neuronal para abordar el mismo problema.

Incluye:

a) Datos necesarios para entrenar el modelo

b) Información que recibiría como entrada

c) Resultado esperado como salida

d) Descripción general del proceso de aprendizaje

e) Una ventaja del enfoque

f) Una limitación del enfoque

No es necesario implementar una red neuronal ni seleccionar una arquitectura específica.

---

### c) Enfoque estadístico/probabilístico

Explica cómo podría representarse la incertidumbre asociada con el mismo problema.

Incluye:

a) Variables que podrían considerarse

b) Evidencia disponible para realizar la estimación

c) Resultado expresado mediante una probabilidad

d) Interpretación de dicha probabilidad

e) Una ventaja del enfoque

f) Una limitación del enfoque

Incluye un ejemplo como:

```text
P(Evento | Evidencia) = valor
```

y explica qué representa en el problema seleccionado.

## Selección del enfoque

Después de completar el análisis, responde:

> **¿Cuál de los tres enfoques considerarías inicialmente más adecuado para resolver el problema seleccionado y por qué?**

Justifica tu respuesta considerando:

a) Tipo de información disponible

b) Disponibilidad de datos

c) Existencia de conocimiento experto
