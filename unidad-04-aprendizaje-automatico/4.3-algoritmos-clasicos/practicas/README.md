# Prácticas de algoritmos clásicos

Las cuatro prácticas avanzan desde el cálculo básico a una comparación aplicada. Cada notebook incluye código ejecutado, resultados, comentarios y consignas. La prueba permanece reservada en P 1–P 3 y se consulta al cerrar P 4. No se necesita descargar datasets de internet.

| Práctica | Notebook | Evidencia |
|---|---|---|
| P 1 · Regresión | [01](../notebooks/01-regresion-lineal.ipynb) | Cálculos, contraste manual/biblioteca, tabla de validación y explicación con unidades. |
| P 2 · Logística | [02](../notebooks/02-regresion-logistica.ipynb) | Comparación de umbrales y reporte multiclase interpretado. |
| P 3 · Naive Bayes y SVM | [03](../notebooks/03-naive-bayes-svm.ipynb) | Comparación por clase y justificación de supuestos. |
| P 4 · Experimento | [04](../notebooks/04-comparacion-experimental.ipynb) | Reporte de 1–2 páginas con selección previa y evaluación final. |

## Secuencia y alcance

Recorrido obligatorio sugerido: P 1 partes 1–2, P 2, P 3 parte 1 y P 4. Extensiones: alteración del dato, variable irrelevante, comparación de kernels en lunas, texto y propuesta de validación cruzada. Se reservan para trabajo independiente según el avance del grupo. No se cambia la calendarización de la unidad.

## Ejecución en Jupyter

Desde la carpeta del subtema: instale dependencias con `python -m pip install -r requirements.txt` y ejecute `jupyter lab`. Abra los notebooks dentro de notebooks/. Use Reiniciar kernel y ejecutar todo. Cada notebook se ejecuta de forma independiente, sin depender de variables de otro.

## Ejecución en Colab

Suba el notebook y los dos CSV de datos/ a una carpeta datos/ del directorio de trabajo, normalmente /content/datos/. No cambie los nombres. Las bibliotecas principales suelen estar instaladas; compruebe las versiones impresas. Puede subir la carpeta completa del subtema mediante Drive y usar ese directorio como directorio de trabajo. El código busca datos/ en el directorio actual o su padre.

## Entrega

Conserve un notebook con salidas y redacte conclusiones propias; pegar resultados sin interpretación no demuestra comprensión. Identifique cambios respecto al ejemplo y no consulte prueba para elegir cambios. Si publica el material, reserve docente/ para retroalimentación posterior.
