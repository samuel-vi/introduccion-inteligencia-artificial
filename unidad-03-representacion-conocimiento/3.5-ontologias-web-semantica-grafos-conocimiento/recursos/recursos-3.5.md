# Recursos complementarios — 3.5 Ontologías en la Web Semántica y grafos de conocimiento

Los siguientes recursos complementan el estudio de RDF, RDFS, OWL, SPARQL, Linked Data y grafos de conocimiento.

## 1. W3C — RDF 1.1 Concepts and Abstract Syntax

Fuente normativa para comprender el modelo RDF y la estructura de triples.

**Contenido de interés:**

a) Recursos

b) IRIs

c) Literales

d) Triples RDF

e) Grafos RDF

Sitio:

https://www.w3.org/TR/rdf11-concepts/

---

## 2. W3C — RDF 1.1 Turtle

Referencia para aprender la sintaxis Turtle.

**Contenido de interés:**

a) Prefijos

b) IRIs abreviados

c) Literales

d) Triples

e) Agrupación de propiedades

Sitio:

https://www.w3.org/TR/turtle/

---

## 3. W3C — RDF Schema 1.1

Recurso para estudiar vocabularios y semántica básica mediante RDFS.

**Contenido de interés:**

a) Clases

b) Subclases

c) Propiedades

d) Dominio

e) Rango

Sitio:

https://www.w3.org/TR/rdf-schema/

---

## 4. W3C — OWL 2 Web Ontology Language Primer

Recurso para reforzar la representación mediante ontologías.

**Contenido de interés:**

a) Clases

b) Individuos

c) Propiedades

d) Restricciones

e) Inferencia

Sitio:

https://www.w3.org/TR/owl2-primer/

---

## 5. W3C — SPARQL 1.1 Query Language

Referencia para consultas sobre grafos RDF.

**Contenido de interés:**

a) `SELECT`

b) Variables

c) Patrones de triples

d) Consultas con varias condiciones

e) Relaciones encadenadas

Sitio:

https://www.w3.org/TR/sparql11-query/

## Preguntas guía

a) ¿Qué representa un triple RDF?

b) ¿Por qué varios triples pueden representarse como un grafo?

c) ¿Qué diferencia existe entre RDF, RDFS y OWL?

d) ¿Qué función cumple un IRI?

e) ¿Qué permite consultar SPARQL?

f) ¿Qué diferencia existe entre una ontología y un grafo de conocimiento?
